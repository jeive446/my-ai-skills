# 人物、场景、镜头与艺术字

1. 音乐：实际母带为时间依据。区分LRC、拍点、乐句、小节和音乐段落；LRC制作信息过滤，不声称未测BPM为实测。故事安排开场、变化、高潮和收束，用视觉母题贯穿，不等长机械分镜。
2. 人物：image-gen确定脸、发型/发色、服装、配饰、体型、身高和性格动作。按镜头需要补侧面/背面/表情；不固定完整三视图。多人分别建立身份参考，另做同框比例参考，防串脸/互换服装。标注各参考管身份、风格、服装或光线，seed不是身份锁。
3. 场景：依音乐和剧情定义主要地点/时间/视觉状态，记录布局、前中后景、人物活动区域、光源、天气与道具状态。环境参考派生不同角度；反打保持空间关系。副歌重复可返回同场，通过人物关系/光色/动作升级。
4. 镜头：每镜记录场景、时间、功能、人物任务、动作、景别、机位、运镜起点路径落点、入/出镜状态、首帧、生成与终剪时长。一个主动作/摄影意图，复杂事件拆镜。靠视线、运动、构图或道具接力，不全靠淡化。
5. 首帧：人物+场景参考融合，按最终画幅留动作和字幕余量。检查实际响应像素，不拉伸或默认中心裁掉人物。角色卡不当成成片背景。末帧可辅助下一镜，但不能无限只用上一帧接龙造成漂移。
6. 艺术字：主标题、段落/小节标题、Hook关键词统一字形气质、材质、色板和装饰。每项准确文字、时间、位置、动效，版本可多、上屏按节奏。不混同每音乐小节和每副歌段落。
7. 校字：逐字检查中文笔画/错漏，确认真实alpha而非棋盘背景。反复出错则用准确中文字体排字再配生成装饰。文字最后叠加，普通歌词重可读，艺术字重强调，避开脸/动作。
8. 方案：人物、美术、主要场景、全曲分镜、配乐静态预剪和艺术字方向一起审看。确认后自动内部样片与批量生成，不逐场景再审批；无法在预算解决时集中报告。

人物不演唱时提示词不放原歌词，描述具体表演与自然口部动作；当前模板不做音频驱动口型。风格不限于像素风，按用户参考将线条、光色、媒介、构图、运动逐镜展开。
